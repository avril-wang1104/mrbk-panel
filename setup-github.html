给咪的仆人一把 GitHub 钥匙 🔑

全程约 5 分钟，做完一次，面板从此永久在线、永不休眠。

一句话概括：注册个账号 → 生成一串密码发给我 → 剩下的我全包。
您可以全程在手机上做，不用开电脑。

① 注册 GitHub 账号

1
手机浏览器（Safari / Chrome）打开：
github.com/signup
2
填邮箱 → 密码 → 用户名（比如 wangjingli888，英文数字即可）→ 完成邮箱验证码
3
中间会问"团队/个人"、用途选择 —— 一律选个人、Just me、跳过问卷即可
⚠ 注册完请先登录着别退出，下一步直接在同一浏览器继续。

② 生成 Token（就是那串钥匙）

1
在同一个浏览器打开这个地址（已登录的话会直达）：
github.com/settings/tokens/new
2
Note（备注）里随便填，比如 每日必看
3
Expiration（有效期）选 No expiration（永不过期，免得以后还得重来）
4
Select scopes（权限）：只勾选 repo 这一组
勾它会自动带上下面 8 个子项，不用管别的
5
滚到最底下点绿色按钮 Generate token
6
生成的密码形如 ghp_xxxx一串很长的字符xxxx，长按复制它，直接发到咱们的对话里
这一串只在生成页露一次，关掉就看不见了。发完记得别把浏览器里那页留在前台。
⚠ 这串密码只能你我能看见，请不要发到群里或朋友圈。我在用它部署完成后，您可以随时在 GitHub 上删掉它再重建；它没有付款、删文件之外的权限。

③ 发给我之后会发生什么

  1. 我自动创建仓库、把面板推上去、开启 Pages —— 全程 1 分钟内
  2. 给您一个新的永久网址，形如 用户名.github.io/mrbk-panel
  3. 我把这个网址写进每天的自动更新任务，从明天早上 8 点起走这条稳定通道
  4. 手机桌面图标需要删掉重加一次（新网址），做完后不再需要我每天踹醒沙箱
关于隐私：GitHub Pages 免费版要求仓库公开，所以网址是不可搜索的长地址，但理论上拿到链接的人能看到内容。 面板里有健康数据，如果您介意，我可以在部署后给页面加一道密码门禁（打开要输入四位数字），这样外人打开只看到输入框。

拿不到 / 不想弄？

那就维持现在的沙箱通道。每天早晨 8 点任务会自动把它叫醒，您起来打开就是新内容；白天遇上休眠，手机会显示缓存里的上一版（不会是错误页）。 想彻底解决随时再来找我。
